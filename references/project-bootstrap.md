# Project Bootstrap

Use this when starting a new Chinese serialized-fiction project or when an existing project lacks enough structure to proceed. These are document roles, not mandatory forms. Keep them short enough to remain useful during drafting.

The `templates/new-project/` directory contains short starting documents. With `SKILL_DIR` set to this installed skill's absolute path, `python3 "$SKILL_DIR/scripts/nml.py" init PROJECT --new-project` adds only missing files; it never overwrites existing project plans. The structured ledger is optional and may be initialized later.

## 00 - Creative Constitution

Record the reader promise, genre and tone, priority order, character boundaries, and any hard content or world constraints. Separate non-negotiable decisions from preferences that can change.

## 01 - Story Specification

Capture the premise, target audience, protagonist's active desire, central opposition, relationship engine, story scope, and intended length. Prefer choices that generate scenes over abstract theme statements.

## 02 - Clarification Questions

Track only unresolved decisions that would materially change the plan or manuscript. Include the question, why it matters, current options, and whether drafting can proceed while it remains open. Do not re-ask settled questions.

## 03 - Chapter Plan

Map arcs and chapters at the level of pressure, choice, cost, reversal, and forward question. Mark uncertain beats as provisional. A plan is an intention record, not proof that the event is canon.

## 04 - Task List

Turn the current plan into concrete writing and review tasks with dependencies and status. Keep completed work visible when it explains the current state; do not use the task list as a second manuscript.

## Existing Projects

Prefer the project's own organization and naming. Do not create duplicate documents just to match these filenames. Before continuing, locate the latest accepted prose, active plan, current character state, unresolved decisions, and any explicitly stale or superseded materials.
