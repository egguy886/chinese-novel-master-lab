# Chinese Novel Master Lab

面向中文连载小说创作的 Codex Skill。它把项目准备、章节计划、正文写作与长篇连续性核对放在同一流程里，让设定核验在后台工作，不打断人物、场景和叙事节奏。

当前为实验版，适合新书准备、按章续写、章节重写，以及需要检查人物状态、知情边界和伏笔接续的长篇项目。单次样章不能证明长期质量，也不承诺固定评分。

## 工作流程

1. 判断任务是新建、续写还是重写，检查现有项目文件和正文进度。
2. 新项目按需整理创作宪法、故事规格、待澄清问题、章节计划和任务清单；已有项目优先沿用现有资料。
3. 写作前准备本章事实卡，明确视角、目标、资源、关系状态、关键物件、人物知情范围和相邻章节接点。
4. 正文经过自由起稿、正典核对、自然语言润色三遍。
5. 写后记录候选状态变化；用户批准前，不自动并入正式正典。
6. 长篇或高风险章节按来源证据检查状态、时间、物件流转、人物知识和章尾承诺。

## 安装

```bash
git clone https://github.com/egguy886/chinese-novel-master-lab.git \
  "$HOME/.codex/skills/chinese-novel-master-lab"
```

或下载仓库后，将整个 `chinese-novel-master-lab` 文件夹放入 `$CODEX_HOME/skills/`；未设置 `CODEX_HOME` 时通常使用 `~/.codex/skills/`。

## 调用

在 Codex 中明确调用：

```text
$chinese-novel-master-lab 帮我建立一部中文长篇小说的前期设定，并规划前十章。
```

```text
$chinese-novel-master-lab 检查现有正文和人物状态，继续写下一章；先列本章必须遵守的事实，再给出正文与候选状态变化。
```

## 产出

按项目现有目录交付章节稿；需要时另附本章事实卡、证据冲突清单和候选状态增量。短篇或单章任务不要求为了流程而新建账本。

仓库不包含任何小说正文或项目私有材料。当前未附开源许可证；公开可见不代表获得复制、修改或再分发授权。
